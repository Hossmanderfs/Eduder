# 05 — Objetivos Específicos

1. Relevar y documentar los requisitos funcionales y no funcionales del sistema mediante técnicas de elicitación (entrevistas, encuestas y análisis de referentes como Duolingo y EBAC).

2. Diseñar la arquitectura del sistema definiendo los componentes, interacciones y nodos de despliegue que soporten los requisitos de disponibilidad, rendimiento y seguridad.

3. Modelar la base de datos hasta la Tercera Forma Normal (3FN), asegurando la integridad referencial y la escalabilidad para 5 000 usuarios concurrentes.

4. Desarrollar el motor de ejercicios interactivos con capacidad de evaluar respuestas y entregar feedback contextualizado en menos de 1 segundo.

5. Implementar el sistema de gamificación (XP, streaks, medallas, ranking semanal) para incrementar la motivación y la constancia en el estudio.

6. Diseñar la interfaz de usuario bajo principios de usabilidad y accesibilidad (WCAG 2.1 AA), con wireframes y prototipo interactivo en Figma.

7. Construir el panel de administración web que permita gestionar usuarios, visualizar métricas de uso y exportar KPIs en formato CSV.

8. Implementar el sistema de notificaciones push y backup automático diario para garantizar la disponibilidad y continuidad del servicio.
